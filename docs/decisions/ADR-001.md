# ADR-001

## Title

Choosing React instead of Next.js

---

## Status

Accepted

---

## Context

The frontend framework for Cortex AI needed to provide flexibility, maintainability, fast development, and a professional user interface.

---

## Decision

React with Vite has been selected.

---

## Reasons

* Lightweight architecture
* Faster development
* Excellent ecosystem
* Easier integration with FastAPI
* Better learning value
* Full control over routing
* Future migration to Next.js remains possible

---

## Consequences

Positive

* Simpler project structure
* Easier deployment
* Lower complexity
* Faster builds

Negative

* No built-in SSR
* SEO requires additional work if needed
